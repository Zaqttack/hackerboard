RULES THAT KEEP IT HONEST

  • The server assigns emoji and fill so the phone reveal matches the board.
  • Names: trim, collapse spaces, 1–20 characters. Hard cap: maxLength="20" on the input (pastes get cut at 20) and the same check on the server. Counter turns red at 20 / 20.
  • One join per device (cookie or localStorage token). "Already on the board" uses the stored name + emoji.
  • Name filter runs server-side. Rejected copy stays friendly and never repeats the name back.

ACCESSIBILITY

  • Every text pair on this sheet is AA or better. Board name text is 10.2:1 minimum.
  • Touch targets: input 60px, button 62px, admin buttons 56–64px.
  • Errors use role="alert" plus a red 3px border and an icon, never color alone.
  • Focus ring: 4px tape yellow, 2px offset, on every interactive element.

  • Cover = bauble area ÷ free board area (1920×1080 minus hero and QR). Tiers keep it under ~50%, so drift and collisions stay readable at any count.
  • Per-bauble variation tightens to ±5% around the tier scale. Floor: name text never under 26px.
  • Crossing a tier: the newcomer lands first, then 400ms later every bauble springs to the new scale over 700ms (--hb-ease-spring), staggered 12ms outward from the newcomer. Reads as the board making room.
  • Tiers only step down on the way up. When the count drops (exit, wipe) they step back up after a 2s delay, so the board never pumps.
  • Physics colliders and string anchors read the scaled size. Reduced motion: scale changes in one 200ms ease-out, no stagger.

16:10 · thin bars top/bottom
  • The board is one 1920×1080 stage, scaled with transform: scale(min(vw/1920, vh/1080)) and centered. Width is capped by the aspect ratio, so an ultrawide never stretches the layout or the physics.
  • Outside the stage: the same cork texture on body, 20% darker (cork-edge), with the vignette strongest at the stage edge. It reads as more corkboard, not black bars.
  • Stage edges are the physics walls. Nothing drifts into the side bands.
  • Why not widen the board: the projector is 16:9, the density tiers assume a fixed area, and a 2560px-wide hero/QR spread is harder to scan from the back row.
  • /join: card max-width 440px, centered on any wider screen. /admin: already a 560px card.
